# Audio Flow Player

Стильний браузерний аудіоплеєр на чистих HTML, CSS та JavaScript.

## Можливості

- завантаження локальних аудіофайлів;
- читання ID3-тегів з mp3: назва пісні, виконавець, альбом і обкладинка;
- кілька стилів візуального блоку: обкладинка, вініл, спектр і постер;
- кольорові теми з автоматичним збереженням вибору;
- анімовані кнопки керування;
- кастомний акцентний колір;
- регулювання заокруглення інтерфейсу;
- компактний режим;
- перемикач анімацій;
- плейлист із перемиканням треків;
- play/pause, next, previous;
- shuffle та repeat;
- прогрес треку, поточний час і тривалість;
- регулювання гучності;
- вибір швидкості відтворення;
- гарячі клавіші;
- адаптивний дизайн для телефону та десктопа;
- підтримка Media Session API у сумісних браузерах.

## Гарячі клавіші

- `Space` - play/pause;
- `ArrowLeft` / `ArrowRight` - перемотка на 5 секунд;
- `ArrowUp` / `ArrowDown` - зміна гучності.

## Запуск

Відкрий `index.html` у браузері. Якщо поруч із файлом є `song.mp3`, він буде доступний як демо-трек. Також можна натиснути `Додати` й вибрати власні аудіофайли.

Якщо mp3 має ID3-теги, плеєр автоматично покаже справжню назву пісні, виконавця, альбом та обкладинку. Якщо тегів немає, буде використана назва файлу і стандартний візуальний fallback.
